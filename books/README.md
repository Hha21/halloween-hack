# Reference Textbooks (`books/`)

Drop reference PDF textbooks (e.g. Raymer *Aircraft Design: A Conceptual Approach*, Bruhn *Analysis and Design of Flight Vehicle Structures*, Megson *Aircraft Structures*) into this folder for `scripts/extract_knowledge.py`.

**Important (Copyright):**
- All files in `books/` (except this `README.md`) and `knowledge/extracted/` are gitignored.
- Never commit PDFs or raw extracted text to GitHub.
- Only curated, human-verified YAML tables and equation citations in `knowledge/` are committed.
